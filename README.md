# anaar-experiments
## Web Slinger

`web-slinger/index.html` is a 3D web-swinging game inspired by the PS5 Spider-Man games, in one self-contained HTML file (Three.js r128 from cdnjs). Open it in a browser to play: hold to swing between skyscrapers with auto-targeted webs, chain swings, swing-jump, wall-run, web-zip to ledges and dive through a procedurally generated city at golden hour. Works with mouse and keyboard, gamepad, or touch.
